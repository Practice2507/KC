# Tâm Thư - Nhật Ký & Lá Thư Tay

Trang web tâm thư viết tay kết hợp hiệu ứng mở phong bì 3D và nhạc nền "toidaidot - GREY D".

## Tính năng
- Hiệu ứng mở phong bì 3D tương tác.
- Tự động phát nhạc mượt mà.
- Hiệu ứng cánh hoa bay lãng mạn.
- Tích hợp thông báo qua EmailJS khi có người mở link hoặc xem thư.

## Hướng dẫn chạy dự án
```bash
npm install
npm run dev
```

## Build dự án
```bash
npm run build
```
